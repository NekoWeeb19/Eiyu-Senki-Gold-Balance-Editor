Define Editor

Drop the extracted text files here: unit.txt, tech.txt, city.txt, item.txt, itemmix.txt, battlestate.txt the extracted BattleSet_*.txt files, and the extracted Episode files (サブミッション.txt, sfr_*.txt, susa編*.txt …) to edit,
plus spot.txt, country.txt, techkind.txt, skill.txt (optional, they add English city / faction / skill-type / map-skill names). You can select the whole extracted folder's files at once; unsupported ones are ignored.
Everything stays in your browser.
Edits are spliced into the original text, so nothing else in a file changes.
